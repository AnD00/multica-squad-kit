## 元の出来事

人間に PR をタスクに紐付けてほしいと頼まれ、リーダーはコマンドを確かめずに「CLI ではできない」と答えた。実際には、紐付けの一覧を読むコマンドがあり、紐付けはタスクの画面でできた。

## 入力

あなたは、スクワッドのリーダーとして起こされました。きっかけは、タスク `issue-shop-1`（SHOP-1「カートに商品数を出す」）に人間が書いたコメント `comment-2` です。返信するときは `--parent comment-2` を使ってください。

コメントの本文: 「PR をタスクに紐付けて」

タスクの状態は `in_progress` です。実装の役が `comment-1` で PR を返しています。

## 合格の基準

1. [記録] 人間への返事を投稿する前に、`--help` か紐付けの一覧を読んでいる。 `判定: before: (issue --help|issue pull-requests) => issue comment add`
2. [採点] 確かめた方法（流したコマンドとその結果）を添えて答えている。確かめずに「できない」と断定していない。
3. [採点] 紐付けをタスクの画面でしてほしいという頼みを、人間への 1 つの頼みにしている。
