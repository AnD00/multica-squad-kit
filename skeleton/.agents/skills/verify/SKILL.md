# プロジェクトの検証

このスキルはプロジェクトに一つ置き、下にリポジトリごとの節を持ちます。checkout したリポジトリの `AGENTS.md` の完了の条件を満たす手順を、対応する節に記入します。今回の検証に必要な欄やリポジトリの節が未記入なら、推測して実行せず、不足を返します。未記入や未実行は成功にしません。

## 作業先の確認

依頼の PR の URL、タスクの metadata の `repository`、またはオートパイロットで指定された一つのリポジトリを使います。自分の役の指示と squad-handoff の作業先の決まりに従い、「このプロジェクトの値」の最新のリポジトリの一覧と照合します。作業先が不明、一覧にない、二つ以上あるときは実行せず返します。

下の節が残っていても、選択から外したリポジトリへの書き込みは許可されません。対象の節だけを使い、コマンド、前提条件、片付けをリポジトリの間で混ぜません。
