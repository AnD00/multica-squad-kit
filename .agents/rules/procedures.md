# 原本の手順の変更

足す条件と見直しの正本は、[CONTRIBUTING.md の手順を足す条件](../../CONTRIBUTING.md#手順を足す条件)と[手順を見直す](../../CONTRIBUTING.md#手順を見直す)です。設計と実装の担当も、この条件に従って記載します。

code-reviewer は、対象の差分に、役に何かをさせる・確認させる・止まらせる文を足すものがあるかを確認します。条件や分岐によって役がすることが増える変更も含め、言い換え・誤りの修正・削除・参照先の変更は除きます。

手順を足す変更があれば、同じ PR の設計の差分、PR に示された設計、PR の本文のいずれかに、防ぐ失敗と働いた跡があるかを確認します。合意された要件による新しい機能では、要件の根拠を失敗の記録に代えられますが、跡は必要です。根拠のタスクの識別子は、正本の決まりに従って Multica のタスクのコメントで確認します。

記載がないときは、このルールか正本の条件を示して、必須の指摘にします。配布する code-reviewer のひな形へ、このリポジトリだけの条件を写しません。
